# Sources des affirmations — pages traitements (hors botox)

Site : medecine-esthetique-liege.be (Dre Jocelyne Fassotte). Relevé le **2026-09-28**. Textes analysés : `textes-traitements.md`.

## Méthode et limites (à lire avant d'utiliser les citations)

- Chaque source ci-dessous a été **ouverte** avec WebFetch le 2026-09-28. Aucune n'est citée d'après un simple résultat de recherche.
- WebFetch ne donne pas la page brute : il passe par un extracteur. Je lui ai demandé des phrases **mot pour mot**, et les citations reproduites ici sont celles qu'il a rendues entre guillemets. Les citations paraphrasées ont été écartées. **Vérifiez chaque citation à la main (Ctrl+F dans la source) avant de la publier.**
- Accès bloqués ou échoués : `curl` depuis le conteneur est refusé par le proxy (403 sur fda.gov et aad.org). pubmed.ncbi.nlm.nih.gov et la plupart des pages pmc.ncbi.nlm.nih.gov renvoient un reCAPTCHA (seules PMC11875574, PMC12121328 et PMC8901212 ont pu être lues). eutils.ncbi a répondu une fois (PMID 29481392), puis robots.txt a bloqué. L'API Europe PMC a répondu 429 (limite de débit). onlinelibrary.wiley.com a répondu 403. La page « aftercare » de l'AAD répond 404. La page NHS sur les fillers n'a renvoyé que sa navigation.
- **Portée des étiquetages FDA :** ils décrivent les produits vendus aux États-Unis sous le même nom de marque (Juvéderm, Restylane, Sculptra, Radiesse). Les notices CE européennes peuvent différer sur les indications et les durées. Pour une source belge, il faut la notice (IFU) CE du lot réellement utilisé par la Dre Fassotte. Ce sont des dispositifs médicaux : ils n'ont **pas de RCP sur e-compendium.be**.
- Statuts : **CONFIRMÉ** = la source dit la même chose. **À CORRIGER** = la source dit autre chose (la version de la source est donnée). **NON SOURÇABLE** = aucune source faisant autorité n'a été trouvée ; c'est souvent une formule marketing.
